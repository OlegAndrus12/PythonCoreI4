Recursive folder walk

read_folder loops over a folder. A file goes to copy_file, which puts it into Backup/<extension>/. A folder makes the function call itself on that folder. Python pauses the current call, finishes the inner one, then carries on with the loop where it stopped. Watch the call stack grow and shrink.

recursive step: if el.is_dir(): read_folder(el)
base case: a folder with no subfolders
the loop ends with no new call → return

      Things to notice
      
      
        
        
      1. There is no if … return. The base case is a folder with no subfolders: the loop runs out without calling read_folder again, so the call returns.
        2. 
        
      2. The indentation in the trace matches the stack depth. Every call returns to the exact loop it came from.
        3. 
        
      3. file.suffix is case-sensitive and copied as is: .PNG and .png, .jpeg and .jpg end up in different folders.
        4. 
        
      4. Folder names start with a dot (Backup/.png), so ls and Finder hide them by default.
        5. 
        
      5. Two files with the same name from different folders: the second copyfile silently overwrites the first.
        6. 
        
      6. A file with no extension has suffix == "", so it lands straight in Backup/.
