Шпаргалка: модулі, пакети та pip

Як працює import і де Python шукає модулі, пакети з __init__.py і __all__, if __name__ == "__main__", pip, віртуальні середовища та публікація свого пакета на PyPI.

Кожен результат Python-прикладу на цій сторінці отримано справжнім запуском у CPython : кожен приклад — в окремому процесі, у теці project/ з файлами, показаними на вкладках (шлях до неї скорочено). Команди терміналу наведено без виводу.
