Caesar cipher

Each letter becomes a number x (A = 0 … Z = 25). The pointer finds the letter on the alphabet ring, then steps key cells forward. Wherever it stops is the new letter. Going past Z wraps back to A, which is what % 26 means.

encrypt: (x + key) % 26
decrypt: (y − key) % 26
in Python: alpha[(alpha.find(letter) + key) % 26]
